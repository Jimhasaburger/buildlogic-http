# buildlogic-http
build logic http api, to modify for your own api.

download code
go into it with a cmd
install dot net if you dont already
run "dotnet run"
or "dotnet watch" if you want live reload

it will be on port 5173 (edit it in properties/launchsettings.json)

you will need a cloudflare tunnel or port forward so that the http transmitter can go on your api,

only GET works, use GET on /data
